# Impact Map (Deprecated)

> **Deprecated:** use `/rhize-devflow:impact-map` instead. The executable workflow — CodeGraph-first
discovery, semantic delta mapping, and post-implementation reconciliation — now lives in the
`rhize-devflow` plugin. This adapter exists only for the 2.12.0 compatibility window and will be
removed no earlier than Dev Flow 3.0.0 / Context Manager 0.15.0+.

Invoke the fully qualified command: `/rhize-devflow:impact-map`. If Dev Flow is not installed,
install `rhize-devflow@rhize-plugins` first — see this plugin's README for the install snippet.
