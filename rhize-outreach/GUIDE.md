# Rhize Outreach operator guide

Use the plugin commands as the normal interface. The local HTML application remains a review surface for candidate cards, website/report previews and the final email.

Setup and dry runs never publish a site or send an email. Gmail begins in `draft_only`; GHL begins in `draft_only` until its location and sender checks pass. A provider timeout with an unknown outcome creates a reconciliation hold.

Tom's handoff package is generated locally after doctor passes. It contains variable names and a copy/paste setup prompt. Each operator completes OAuth and Keychain entry on their own Mac.
