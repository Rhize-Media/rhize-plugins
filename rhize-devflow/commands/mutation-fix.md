# Mutation Fix (Deprecated)

> **Deprecated:** use `/rhize-devflow:mutation-check --fix-plan` instead. Fix-plan
generation is now one mode of the consolidated mutation-check command, and no longer
supports `--add-todos`/`--apply` — the consolidated command is read-only. This adapter
exists only for the 2.12.0 compatibility window and will be removed no earlier than Dev
Flow 3.0.0.

Invoke the fully qualified command: `/rhize-devflow:mutation-check --fix-plan`.
